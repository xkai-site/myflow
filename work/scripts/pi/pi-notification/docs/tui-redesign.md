# /notify TUI 重设计与验收

## 任务与路径

设计基于本地源码，不改运行事件、规则筛选、消息 API 或投递语义。Image 的参照点是明确的任务入口、取消边界和结果反馈，不是把常驻通知设置变成线性向导。

| 用户任务 | 原路径/负担 | 新路径 |
| --- | --- | --- |
| 首次打开，确认能否提醒 | 首页开关不等于能投递；阻断信息在诊断中 | 首页先显示生效状态、必要原因和未保存数量，再显示任务 |
| 调整完成/失败/等我回复 | 打开字段候选、选值、退回；Space 快捷方式不够显著 | 提醒时机页 Enter/Space 原地切换，完成/失败优先排列 |
| 临时改一次 | 修改生效，但与长期配置关系依赖反复说明 | 明确“仅本对话即时生效”；详情仍能看三层来源 |
| 以后也这样 | 逐项 Ctrl+S，没有总览 | 首页批量保存，先审查具体字段、值与范围；默认取消 |
| 只保存一项 | 易误以为保存悬停候选/整页 | 保留 Ctrl+S，只保存当前项已生效值；专业搜索仍能打开候选 |
| 配置邮箱 | 地址→候选→自定义输入；说明与动作混排，占用焦点 | 地址直接输入；就绪条件、下一步、启用、测试、默认保存同页 |
| 排查收不到 | 配置状态、限制、渠道结果分散 | 首页说明限制；显式测试报告各渠道结果；诊断保留技术统计 |
| 恢复设置 | 易把恢复用户默认与出厂重置混淆 | `?` 中 `a` 清本对话覆盖；`d` 默认取消，明确范围后删默认 |

## 信息架构

```text
通知控制中心
├─ 当前生效状态 / 必要阻断原因 / 未保存数量
├─ 提醒总开关（Enter/Space 原地切换）
├─ 提醒时机（Enter/Space 原地切换）
├─ 接收方式（多选；保留规则例外提示）
│  └─ 邮箱任务页（可自由返回，无强制连续步骤）
├─ 发送测试通知
├─ 更多设置
│  ├─ 内容与隐私 / 免打扰
│  ├─ 专业设置（逐规则、渠道开关、邮箱主题）
│  └─ 诊断 / 重读 / 搜索
└─ 保存本次修改为以后默认 → 范围确认（默认取消）
```

- **日常任务直接操作，专业字段渐进展开。** 不把 inherit、API 或可靠性参数放在首页。提醒摘要也计入工具失败/中止，避免普通三项关闭时误报所有提醒都关闭。
- **覆盖存在性与未保存是两件事。** 原配置优先级不变；未保存数量只统计有本对话覆盖、且当前值不同于以后默认的实际字段。普通/逐规则入口去重，失败复合开关可能计两项；已保存的会话覆盖继续保留。
- **批量保存是一次稀疏事务，不是循环单项写盘。** 确认时列明范围。首页保存所有待保存的界面字段；邮箱页只保存邮箱选项/开关与统一接收选择，不夹带其它提醒/隐私修改。不快照无关已选渠道开关、API 或 JSON 专业参数。
- **邮箱准备不触发外发。** 填地址、存凭据不会自动启用、选中或测试。启用仍要明确确认；测试仅由用户执行。失败不回滚路由；修改地址/凭据后旧结果失效。保存默认不以测试成功为硬门槛，用户可先保存准备中的配置；“下一步”仍如实指出未完成条件。
- **不把“服务接受”说成“已收到”。** 测试跟踪排队、发送、各渠道提交/失败；保留强制静默/总开关/渠道开关边界。
- **紧凑不是隐藏可访问性。** 删除固定空白与重复说明；最多 12 个可见列表行，而非强制占满 12 行。保留纵向分页、候选标记、父页焦点与 Esc 返回；文本输入由 Pi Input 处理光标、横向滚动与 IME 标记，父组件传递 focused。
- **主题跟随宿主。** 原生 SelectList/Input；焦点使用 accent/bold；状态使用 success/warning/error；说明使用 muted/dim。删除原 QQ 链接的硬编码 ANSI 蓝色，仍有明确的浏览器打开动作。

## 工程拆分

- `src/ui-model.ts`：无 IO 的控制状态、邮箱条件/下一步、待保存字段与批量补丁。它只解释配置，不替代投递服务的最终筛选。
- `src/ui-primitives.ts`：Pi 原生列表/文本输入适配、独立 SaveReview 的渲染/输入与分页。
- `src/ui-secret.ts`：凭据私有输入状态、有限分块粘贴、遮蔽光标与取消/销毁清理；不用会保留明文 undo/kill ring 的普通 Input，不向 JSON/调试状态暴露值。
- `src/ui.ts`：导航与现有专业设置、测试结果反馈，接入上述模块。单项恢复后刷新页面，保留焦点。
- `src/commands.ts`：提供运行态限制、连接一次原子批量写入；凭据仍走原系统凭据服务，实际测试仍走原投递服务。直接返回 Focusable 组件，避免包装丢失焦点。
- `src/settings.ts`：调整常用项顺序与提示、补全实际提醒摘要；空邮箱值明确显示“未配置”。配置键、patch、inherit 与显式数组语义不变。

没有新增依赖，没有改通知事件/消息 API/规则/投递实现。
